Fanak 변환기 사용 설명서
===================
261103 ver 1.0

탐색기에서 파일을 끌다가 키 하나만 누르면 이미지·PDF를 변환하고,
이미지를 자르고, DPI를 바꾸고, 문서를 PDF나 Markdown(MD) 등으로 바꿀 수 있는 프로그램입니다.
파일은 PC 안에서만 처리하며 외부로 보내지 않습니다.


설치
----
설치할 것이 없습니다. 이 폴더를 원하는 곳에 복사하고 Fanak.exe를 실행하세요.
Windows 10 또는 11에서 사용할 수 있습니다.

처음 실행하면 사용법 창이 열리고, 작업 표시줄 오른쪽 트레이에 사막여우 아이콘이 생깁니다.

"PC 보호" 경고가 뜨는 경우:
  인터넷으로 받은 파일이면 코드 서명이 없어서 나타날 수 있습니다.
  "추가 정보"를 누른 뒤 "실행"을 누르면 됩니다.
  프로그램이 전역 마우스 감지를 쓰기 때문에 백신이 경고할 수도 있습니다.
  믿을 수 있는 경로로 받은 파일일 때만 허용하세요.


사용법
------
1. 탐색기나 바탕 화면에서 파일을 끌기 시작합니다.
2. 끄는 중에 ` 키(숫자 1 왼쪽)를 누르면 메뉴가 열립니다.
3. 원하는 항목 위에 놓습니다. 가운데에 놓으면 취소됩니다.

결과는 원본과 같은 폴더에 저장됩니다.
원본은 바뀌지 않고, 같은 이름이 있으면 번호를 붙입니다.

시간이 걸리는 변환은 화면 오른쪽 아래에 진행 창이 뜨고, "취소"로 멈출 수 있습니다.
PDF → MD처럼 프로그램 안에서 처리하는 변환은 진행 중인 파일이 끝난 뒤에 멈춥니다.
끝나면 같은 자리에 "파일 열기"와 "폴더 열기"가 나타납니다.
메뉴는 이미지 형식, 문서 형식, 자르기·DPI 순으로 밝기가 달라집니다.


기능
----
이미지 변환    PNG, JPG, TIFF, BMP, GIF
PDF 만들기     이미지를 PDF로 저장 (여러 장은 이름순으로 한 파일에 합침)
PDF → 이미지   페이지마다 PNG, JPG, TIFF 파일 하나로 저장
자르기         창에서 영역을 지정해 저장 (이미지 한 장일 때)
DPI            값을 바꿔 저장한 뒤, 저장된 파일을 다시 읽어 확인
MD 변환        Word(.docx), PowerPoint(.pptx), Excel(.xlsx), PDF,
               한글(.hwp .hwt .hwpx .hwtx .owpml .hml .hwpml),
               텍스트(.txt .csv .tsv .html .htm .rtf)를 Markdown 파일로 저장
               (Word, 한컴오피스 등이 없어도 됩니다)
문서 → PDF     Word(.doc .docx .docm), PowerPoint(.ppt .pptx .pptm),
               Excel(.xls .xlsx .xlsm), 텍스트(.txt .html .htm .rtf),
               한글(.hwp .hwt .hwpx .hwtx .owpml .hml .hwpml)을 PDF로 저장
               (이 기능은 해당 프로그램이 설치된 PC에서 쓸 수 있습니다.
                텍스트 파일은 Word가 필요합니다. 없으면 메뉴에 나타나지 않습니다)
한글 ↔ 워드    한글 문서를 DOCX로, Word 문서(.doc .docx .docm)를 HWP로 저장
               (한컴오피스가 필요합니다. Word는 .doc 파일을 바꿀 때만 필요합니다)
표 → Excel     .csv .tsv를 XLSX로 저장 (다른 프로그램이 없어도 됩니다)

한글이 필요한 변환(한글 → PDF, DOCX / Word → HWP)은
열려 있는 한글 창을 저장하고 닫은 뒤 해 주세요.


변환 결과에서 알아 둘 점
------------------------
한글 ↔ 워드
  글자, 표, 그림은 옮겨지지만 쪽 배치는 달라질 수 있고, 쪽수가 크게 늘기도 합니다.
  양식이 중요한 문서는 결과를 꼭 확인해 주세요.

Excel → PDF
  인쇄 설정이 없는 시트는 가로로 잘리지 않게 폭을 한 쪽에 맞춥니다.
  열이 많으면 글자가 작아질 수 있습니다. 원본 파일은 바뀌지 않습니다.

.csv .tsv → XLSX
  007처럼 0으로 시작하는 코드와 15자리를 넘는 숫자는 글자로 그대로 둡니다.
  =로 시작하는 값도 수식으로 실행되지 않고 글자로 들어갑니다.

.html → PDF
  파일이 PC 밖으로 나가거나 외부에 접속하지 않도록 인터넷에 있는 그림과 스타일은
  불러오지 않습니다. 같은 폴더의 그림은 들어갑니다.


MD 변환 결과
------------
Word, PowerPoint, Excel, 한글
  제목, 굵게·기울임, 목록, 표, 그림, 링크, 각주를 그대로 옮깁니다.
  그림은 "파일이름_images" 폴더에 저장되므로 MD 파일과 함께 옮기세요.
  차트와 도형 그림은 옮겨지지 않을 수 있습니다.

PDF
  PDF에는 글자의 위치만 들어 있어서 제목, 문단, 표를 위치로 추측해 복원합니다.
  글자는 대부분 정확하지만 구조는 원본과 다를 수 있으니 중요한 문서는 확인해 주세요.
  - 한글이 줄 끝에서 나뉜 곳에 띄어쓰기가 들어갈 수 있습니다.
  - 선이 없거나 칸이 복잡한 표는 표가 아닌 글로 나올 수 있습니다.
  - 벡터로 그린 차트와 도형은 옮겨지지 않습니다. 사진 같은 이미지만 옮깁니다.
  - 링크는 글자만 남습니다.

스캔한 PDF
  Windows의 글자 인식(OCR)으로 읽습니다. 잘못 읽은 글자가 있을 수 있고,
  표는 글로 나옵니다. Windows에 해당 언어 팩이 있어야 합니다.
  없으면 해당 쪽을 그림으로 넣습니다.
  어느 쪽을 이렇게 처리했는지는 MD 파일 맨 위 주석에 적힙니다.

옛 형식(.doc .ppt .xls)은 MD로 바꿀 수 없습니다.
각 프로그램에서 새 형식(.docx .pptx .xlsx)으로 저장한 뒤 변환하세요.

한글 문서
  한글 97 이전의 3.0 형식 .hwp도 읽습니다. 다만 3.0 형식에는 줄바꿈과 취소선이
  저장되지 않으며, 개요 번호와 글머리표는 글자 그대로 나옵니다.
  암호가 걸린 문서, 배포용 문서, 보안 문서는 변환할 수 없습니다.


설정
----
Fanak.exe를 다시 실행하거나 트레이 아이콘을 더블클릭하면 설정이 열립니다.

  메뉴 호출 키    원하는 키로 변경 (최대 3개 조합)
  기본 DPI        DPI 창의 처음 값이자 PDF를 이미지로 바꿀 때의 해상도
  완료 알림       변환이 끝났을 때 알림 표시 여부
  자동 실행       Windows 로그인 시 자동 실행 여부

설정은 이 폴더의 settings.ini에 저장됩니다.
다른 사람에게 폴더를 줄 때 이 파일을 지우면 처음 상태로 전달됩니다.


종료와 삭제
-----------
트레이 아이콘을 우클릭해 "종료"를 누릅니다.
삭제하려면 설정에서 "Windows 시작 시 자동 실행"을 끈 뒤 종료하고 폴더를 지우세요.
변환 기록은 %LOCALAPPDATA%\Fanak 폴더에 있습니다. 함께 지워도 됩니다.


알아 둘 점
----------
- 움직이는 GIF나 여러 페이지 TIFF는 첫 프레임만 사용합니다.
- 이미지의 투명한 부분은 JPG, BMP, PDF에서 흰색이 됩니다.
- GIF에는 DPI를 저장할 수 없어서 DPI를 바꾸면 PNG로 저장합니다.
- DPI 정보가 없는 이미지는 96 DPI로 간주합니다.
- WebP와 HEIC는 Windows에 해당 코덱이 있어야 읽을 수 있습니다.
- 암호가 걸린 PDF는 열 수 없고, PDF끼리 합치거나 나누는 기능은 없습니다.
- 관리자 권한으로 실행한 창에서 끌어온 파일은 받을 수 없습니다.
- 배율이 서로 다른 모니터를 함께 쓰면 메뉴 위치가 어긋날 수 있습니다.
